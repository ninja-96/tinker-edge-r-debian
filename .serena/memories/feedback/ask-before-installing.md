When something needs to be installed or changed on the user's PC (or the board) — apt packages, binaries, config — ask first and let the user do it or approve it. Example: during the 2026-11-05 release test, sudo apt install iperf3 was needed for the network phase of test-board.sh; the user installed it themselves after asking why. The sudo password of the PC is unknown to the assistant and must not be requested to store. Related: mem:reference/test-board-password, mem:project/tinker-edge-r.
