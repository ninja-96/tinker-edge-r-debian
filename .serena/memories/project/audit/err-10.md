# 10. build-npu-boot.sh молча подставляет чужой firmware

(ERRORS.md #2, аудит 2026-11-23.) `python3 scripts/npu-fw-tinker.py ... || cp $SRC/boot.img` — при любом ненулевом выходе берётся исходный EVB-образ.
**Проблема.** Нет dtc / прошивка обновлена / текст DTB изменился → EVB-дерево (I2C-регуляторы): «galcore: failed to get regulator», NPU перезагружается при загрузке модели, сборка «успешна».
**Исправление.** 4723a66: npu-fw-tinker.py идемпотентно пропускает уже запатченный (или ASUS) образ (exit 0, байт-в-байт); fallback `|| cp` удалён — set -e останавливает сборку на любом другом падении.
**Статус:** Закрыта, 2026-11-24. Проверка: сборка прошивки NPU прошла (out/npu_fw/boot.img, 686 файлов в ramdisk).
