# 24. build-rootfs.sh без кэша — самый долгий этап гоняется заново

(ERRORS.md #16, аудит 2026-11-23.) mmdebstrap (apt-скачивания) при каждом запуске, 10+ минут; соседние emulated-chroot-скрипты имеют stamp-проверки.
**Исправление.** 5709764: STAMP = хеш скрипта + FREE рядом с out/rootfs.tar; совпало — skip, FORCE=1 пересобирает.
**Остаток.** Ключ не включает FORCE_PW_CHANGE/имя хоста/юзера (и обход кеша для нестандартного пароля), FORCE не передаётся run.sh в контейнер → карточка 8.
**Запись истории:** Закрыта (остаток → карточка 8), 2026-11-24.

**Сверка всех карточек, 2026-11-24, f86b309.** Повторный запуск build-rootfs.sh во временном каталоге с неизменной политикой использовал stamp и не вызвал mmdebstrap повторно. Проверка содержимого архива при смене политики относится к № 8.
