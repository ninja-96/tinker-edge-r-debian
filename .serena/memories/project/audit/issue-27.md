# 27. USB-descriptor-скан скопирован в двух файлах

(ERRORS.md #19, аудит 2026-11-23.) Идентичный код «найди 2207:0019, парси descriptor с оффсета 18, возьми интерфейс 0xff/0x4e/0x50, claim» в rk3399pro_npu.cc (usb_open) и npu_daemon.cc (usb_open).
**Проблема.** Прошивка NPU добавит третий endpoint — правку придётся делать в двух местах.
**Отложено.** Дедупликация в общий header; любое изменение проверяется только на плате.
**Запись истории:** Отложена, 2026-11-24.
