# 15. autotune не разгружает модель, если попытка упала

(ERRORS.md #7, аудит 2026-11-23.) В trial-лямбде rk3399pro_npu.cc m.stop() внутри try; на исключении (NPU-глюк, таймаут) движок остаётся на кристалле (Model::close роняет только локальный линк).
**Исправление.** 18222fc: Model* вне try; stop() + delete после catch (игнорируя «no such model»).
**Запись истории:** Закрыта (локально), 2026-11-24. Проверка: компиляция.

**Сверка всех карточек, 2026-11-24, f86b309.** Нативная Model::autotune получила от тестового демона ошибку RUN первого пробного кандидата (ID 2). До возврата ошибки пользователю сервер получил UNLOAD для ID 2. Наблюдались отдельно выгрузка исходной модели и выгрузка неудачного кандидата. Проверена очистка при отказе RUN; утечка аренды после успешного autotune отдельно в № 2.
