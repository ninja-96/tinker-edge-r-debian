# 5. Аудит free-образа сообщает об успехе при нечитаемом rootfs

**Где и почему.** В `scripts/audit-free.sh` проверяется наличие программы `debugfs`, но её диагностика скрыта, а пустой вывод трактуется как отсутствие запрещённых файлов и пакетов. На синтетическом образе с совпадающими байтами загрузчика и без файловой системы проверка вернула код 0 и `RESULT: free`. Этот код принимает `scripts/make-free-image.sh`.

**Что изменить.** Сначала подтвердить, что читается именно корневая ext4 проверяемого образа по смещению сборщика. Проверить непустые осмысленные данные из обязательных `/var/lib/dpkg/status` и `/etc/apt/sources.list`. Для необязательных путей различать штатное отсутствие и ошибку чтения. Если установленный `debugfs` не читает образ со смещением, извлечь раздел из проверяемого файла во временный файл и читать его. Не подменять его соседним `out/rootfs.ext4`. Возвращать ненулевой код при неполной проверке и выводить конкретную причину.

**Приёмка.** Сделать маленькие локальные образы с известным загрузчиком. Чистый читаемый раздел проходит. Неверное смещение, отсутствие ext4, отсутствие обязательного файла, запрещённый файл и пакет из `non-free-firmware` дают ненулевой код. Запускать сам скрипт и проверять одновременно сообщение и статус процесса.

**Запись истории:** Исправлено локально, ожидает платы. 2026-11-24, коммит 3d3ce02. Гейт читаемости на смещении сборщика (dpkg/status и sources.list обязаны ответить), извлечение раздела во временный файл вместо соседнего rootfs, stat в трёх состояниях (есть/нет/ошибка чтения → exit 2 с причиной). Приёмка на синтетических образах: 7/7 (чистый раздел проходит; неверное смещение, отсутствие ext4, отсутствие обязательного файла, запрещённый файл, non-free пакет, неверный загрузчик — ненулевой код и причина). Реальный free-образ и плата — ожидает.

**Проверка f86b309, 2026-11-24.** На синтетическом ext4 с блоком 1024 байта первый блок dpkg/status читается и начинается с Package. Второй блок с Section: non-free/misc недоступен. debugfs cat вернул 1024 байта и диагностику short read. Штатный audit-free.sh вернул 0 и RESULT: free; полностью отсутствующий ext4 дал 2. Проверять полное чтение обязательных данных до анализа и сообщать о неполной проверке с кодом 2. Регрессия должна покрывать отказ после успешно прочитанного префикса.

**Сверка всех карточек, 2026-11-24, f86b309.** Сверены try_root и чтение dpkg/status через dbg. Путь, на котором короткое чтение после первого блока было принято за полный список пакетов, остался прежним. Предыдущий тест на этой ревизии вернул 0 вместо 2.

**Итоговая приёмка, 2026-11-24.** Новый read_full: обязательные /var/lib/dpkg/status и /etc/apt/sources.list должны читаться целиком — короткое чтение после успешно прочитанного префикса или нулевой (обрезанный) блок, который bash читает как пустой, — ошибка чтения: exit 2, причина выводится, строки RESULT нет. cat_root усилен так же (сравнение количества прочитанных байтов с размером из stat). Приёмка на синтетических образах: 15/15, включая регрессию сверки f86b309: первый блок dpkg/status читается и начинается с Package, второй блок — short read → exit 2 без RESULT.
