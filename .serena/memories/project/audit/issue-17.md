# 17. Кэш скомпилированного графа мёртв для моделей с >16 входов/выходов

(ERRORS.md #9, аудит 2026-11-23.) do_load_nbg на кристалле ограничивает 16 тензоров на сторону; хост пишет NBG-кэш при любой модели → «bad tensor description» и полная перекомпиляция навсегда.
**Исправление.** 18222fc: на хосте NBG-кэш не пишется, если n_inputs или n_outputs > 16.
**Запись истории:** Закрыта (локально), 2026-11-24. Проверка: компиляция.

**Сверка всех карточек, 2026-11-24, f86b309.** Нативная библиотека с тестовым демоном не записала новый NBG для 17 входов. Затем в кеш по действительному имени добавлен NBG старого формата с 17 входами. Два последовательных открытия оба отправили LOAD_NBG, получили отказ и выполнили LOAD; старый файл остался. До отправки проверить сохранённые счётчики и игнорировать устаревший неподдерживаемый граф. Приёмка: ни один запуск с таким файлом не отправляет LOAD_NBG, поддерживаемый граф по-прежнему переиспользуется.

**Итоговая приёмка, 2026-11-24.** Перед отправкой Model::load проверяет сохранённые счётчики шапки кэш-файла (u32 n_in / u32 n_out): граф с более чем 16 тензорами на сторону игнорируется (сообщение в stderr, файл остаётся на месте — LOAD вместо LOAD_NBG); путь записи не пострадал (та же защита 16/16). Приёмка с фейковым демоном: два последовательных открытия модели при файле с 17 входами в кеше — оба plain LOAD, ни одного LOAD_NBG; при файле с 16 входами — LOAD_NBG (граф переиспользуется).
