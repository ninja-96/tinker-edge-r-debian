# 32. Тест Chromium принимает открытое устройство за декодирование

2026-11-27. Старый тест искал video/dma_heap у всех процессов Chromium в системе и запускал браузер headless через file://. Посторонняя вкладка могла дать PASS даже при зелёном кадре. scripts/board-selftest.sh и scripts/check-browser-decode.py запускают отдельный профиль на Wayland, проверяют GPU и Media-события для тестовой страницы и цвета в двух снимках области видео. Для закрытия нужны PASS на плате с новым драйвером и отказ при программном декодировании.

Закрыта 2026-11-27. Проверен отрицательный результат на плате: видны оба цвета, но FFmpegVideoDecoder даёт FAIL. После исправления драйвера Chrome DevTools подтвердил VaapiVideoDecoder, Panfrost и оба цвета по снимкам области видео. Фазы VA-API и Chromium дали PASS отдельно и в полном запуске. На серверном образе проверка временно запускает Weston, в существующем Wayland использует текущую сессию.
