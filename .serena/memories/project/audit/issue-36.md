# 36. Статический BROADCAST_TO на выходе графа падает при первом запуске

На RK3399Pro со штатной прошивкой LiteRT 2.4.0 воспроизводится у INT8 и UINT8 для [1,8,1,4] → [1,8,8,4]. CPU выполняет исходный граф. VX BroadcastToMapper подставляет вход следующему слою и не материализует выходной тензор. В npu-open/server/rewrite_ops.h фиксированный broadcast одного ранга материализуется существующим путём CONCATENATION. Ограничения: положительная статическая форма, постоянный INT32 target, одинаковая per-tensor квантизация, до 64 повторов по оси. Приёмка: make_quantized_ops.py и compare_quantized.py; холодная загрузка, все узлы на NPU, оба типа совпадают с CPU на восьми входах. Проверять на версии прошивки из исходников, старые NBG исключить.
