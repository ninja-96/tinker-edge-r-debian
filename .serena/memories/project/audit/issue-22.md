# 22. Пароль на удалённой командной строке

(ERRORS.md #14, аудит 2026-11-23.) `ssh ... "echo '$PASS' | sudo -S"` — одинарная кавычка ломает команду, метасимволы — инъекция, пароль виден в /proc процесса echo.
**Исправление.** 5709764: `printf '%s\n' "$PASS" | ssh ... "sudo -S -p '' ..."` (ssh прокидывает stdin) в update-kernel.sh и test-board.sh; заодно mktemp без -u (race на симлинк).
**Запись истории:** Закрыта (локально), 2026-11-24. Проверка: bash -n. Без прогона по SSH.

**Проверка f86b309, 2026-11-24.** scripts/update-kernel.sh и scripts/test-board.sh запущены с локальными заменами ssh и scp и синтетическим паролем с кавычкой, пробелами и знаком доллара. В argv SSH пароль отсутствовал, а его строка в stdin команды sudo совпала целиком для обоих вызовов. Удалённое выполнение sudo не требовалось для проверки передачи.

**Сверка всех карточек, 2026-11-24, f86b309.** Код обеих SSH-команд совпадает с ранее проверенным на f86b309. Сохраняется подтверждение, что синтетический пароль передан через stdin без попадания в argv. Ошибка распространения кода SSH ведётся отдельно под № 30.
