# 18. Мёртвый движок остаётся в списке, «стопнутый» RUN не чистит его

(ERRORS.md #10, аудит 2026-11-23.) NPU_LIST/DESCRIBE не смотрят e->pid; RUN при e->pid<=0 отвечает ошибкой вечно; запись с pid=-1 живёт до ручного stop(id).
**Исправление.** 2e81d29: RUN/OPS с мёртвым движком — lk.unlock() затем engine_remove (deadlock исключён: stopper сначала стирает запись из g_engines, потом берёт e->mu; lost-race — безопасный no-op).
**Статус:** Закрыта (локально), 2026-11-24. Проверка: компиляция, порядок блокировок по исходникам.
