# 12. «fully free» образ собирается с закрытыми бинарями, аудит не видит

(ERRORS.md #4, аудит 2026-11-23.) make-free-image.sh: USE_TFA=1 не выставлен, UBOOT_BIN не переопределён (build-uboot.sh берёт закрытый BL31 из blobs/, образ — ddrblob-вариант); аудит сравнивает только сектор 64 с локальным файлом; audit-free.sh без set -e, dbg() глотает ошибки.
**Исправление.** 445206f: export USE_TFA=1 и UBOOT_BIN; guard debugfs (exit 2); build-image отклоняет ddrblob-U-Boot при FREE=1.
**Остатки.** UBOOT_BIN — абсолютный путь хоста, а run.sh монтирует репо в /work (тихий фолбэк на у-boot-rockchip.bin), внешний BL31 приоритетен над USE_TFA → карточка 7. Ложный успех аудита при пустом выводе debugfs (нечитаемый/отсутствующий ext4) → карточка 5.
**Запись истории:** Закрыта (остатки → карточки 5, 7), 2026-11-24.

**Сверка всех карточек, 2026-11-24, f86b309.** В штатном входе free-сборки явный выбор открытых артефактов подтверждён запуском со внешними переопределениями и заглушками этапов. Сохраняется прежнее разграничение карточек: происхождение собранного BL31 проверяет № 7, неполный аудит образа описан в № 5 и 29. Статус № 12 не подтверждает готовность релизного образа.
