Serena's `fs.search_for_pattern` / `find_file` skip gitignored paths by default (`skip_ignored_files=True`) — the big trees of this project are gitignored: build/ (kernel + obj), reference/ (vendor kernel 4.4, rk-kernel-6.12, rkbin, tf-a sources), out/ (build products), downloads/ (sources). For searches in those trees pass `skip_ignored_files=False` (optionally with `relative_path="reference"` etc.). Project code (dts/, kernel-mods/, scripts/, docs/, config/) is searchable the usual way. Keep the session id from `initial_instructions` (it changes per session); call the REPL via `serena_serena_repl` with `s.<facade>` calls — only the last expression is returned, `print()` output is not captured.
