# Boot logo

`debian-openlogo-white.svg`: the [Debian Open Use Logo](https://www.debian.org/logos/) (the swirl, without the word), recoloured white for a black
screen. It is the only artwork of the boot splash: U-Boot, the kernel's boot logo and the Plymouth theme show it centred on black at any resolution.
`scripts/make-boot-logo.sh` makes the images of each stage from it at build time.
